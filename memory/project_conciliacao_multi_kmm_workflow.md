Conciliação Multi x KMM: source SQL is `C:\project\Apolo11\conciliacao_multi_kmm.sql`, runbook with full history in `C:\project\Apolo11\atualizar_conciliacao_multi_kmm.md`. Live table `hml_gold.fato_conciliacao_multi_kmm` (always this name) is repointed with `ALTER TABLE ... SET LOCATION` to a new `_vNN` CTAS (at 2026-10-09 it points to `_v53`, 105 columns, 332k rows; next is v54). Always ASK before creating a version/table (user rule, hml_ only). Process that works: `ALTER TABLE ADD COLUMNS` on the live table, dump live schema, `build_ctas.py` (CAST to live types), validate the new table, `SET LOCATION`, `select *` test. Power BI model: `C:\PowerBIClaudio\14 - Controladoria\AnaliseDocumentos.pbip` (table DocumentosFato reads `select * from hml_gold.fato_conciliacao_multi_kmm`).

**Why:** SET LOCATION keeps the OLD Glue schema, so new files must have identical column names/types/order (CAST in the CTAS: kmm_doc_id bigint, 6 valor_* double); otherwise Power BI fails with HIVE_CURSOR_ERROR. `count(*)` doesn't catch it — run `select *` after the swap and roll back if it fails.

**How to apply:**
- AWS CLI: `~/.aws/config` has `output = aws` (broken) -> `export AWS_DEFAULT_OUTPUT=json`; the SQL is too big for argv -> use `--cli-input-json file://`. Workgroup `cootravale-s3-athena`, db `hml_gold`, bucket `s3://cootravale-layer-gold/hml/gold/`.
- KMM bronze keys num_conhecimento/num_nota_fiscal are decimal(38,18): CAST to bigint before varchar when building text keys.
- Multi `cli_cgccpf_terceiro` can be a 15-digit internal code (1+zeros+id); real doc is `multi_dbo_t_cliente.cli_cnpjcpf`.
- `valor_fatura` / `margem_bruta` in the table are inflated (full fatura repeated per document); BI uses `valor_documento_kmm` as revenue. Not yet fixed in SQL (also affects prd_gold.vw_conciliacao_rentabilidade).
- Business margin = on NET revenue (valor_documento_kmm - valor_icms_kmm - valor_iss_kmm, only active docs con_status A/S); cost = SUM of ALL contract titles (adiantamento+saldo, fixed in v43 via pagar_agregado), once per carga (linha_custo_carga=SIM). User-validated on cargas 233269 (8%) and 206915. 2026 total margin ~20.6%.
- Tomador display = grupo_tomador (fallback nome_tomador), column `Cliente (grupo)` in the model.
- Origem do lançamento: `usuario_doc_kmm` (93rd column, added v45 via ALTER TABLE ADD COLUMNS before SET LOCATION). SISTEMA = INTEGRADOR_MULTI + KSS (user confirmed KSS is system), MANUAL = person users. Faturas are always manual, not measured. BI measures use KEEPFILTERS on the user column.
- Tooling on this machine: PowerShell Add-Type (C# for mouse clicks) can fail with "acesso negado" on temp DLL — use Python ctypes (user32 SetCursorPos/mouse_event/keybd_event) + PIL ImageGrab instead; open the pbip with os.startfile (cmd `start` mangles "14 - Controladoria"); taskkill without /F asks Desktop to close (no dialog = nothing unsaved).
